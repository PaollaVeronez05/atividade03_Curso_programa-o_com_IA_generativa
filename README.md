

#  Atividade 03 — Programação com IA Generativa

## 📌 Sobre o Projeto

Este repositório apresenta a **Atividade 03 do curso de Programação com Inteligência Artificial Generativa**, com foco na aplicação prática de ferramentas de IA no desenvolvimento de software.

O projeto explora como a **IA generativa pode ser integrada ao processo de programação**, auxiliando na criação, otimização e organização de código.

A utilização de ferramentas como **GitHub** e **IA generativa** permite aumentar significativamente a produtividade e qualidade no desenvolvimento de sistemas ([Serpro][1]).

---

## 🎯 Objetivo

* Aplicar conceitos de programação com apoio de IA
* Utilizar ferramentas inteligentes no desenvolvimento
* Aprimorar a lógica e estrutura de código
* Explorar a automação de tarefas com IA

---

* 🤖 **IA Generativa (ex: ChatGPT, GitHub Copilot)**

Ferramentas como o **GitHub Copilot** utilizam IA para sugerir códigos, acelerar o desenvolvimento e auxiliar na aplicação de boas práticas ([Udemy][2]).
